Demand Forecasting Engine

An interactive time-series forecasting application powered by WebAssembly (Pyodide) to run enterprise-grade econometric models entirely in the browser. Features custom CSV uploads with interactive header mapping, multi-periodicity resampling, dynamic seasonal period handling, and multi-model prediction (ETS, SARIMAX, Theta) with adjustable confidence intervals.
