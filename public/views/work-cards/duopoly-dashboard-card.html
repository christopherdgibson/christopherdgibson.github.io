Duopoly Pricing Engine

An interactive Monte Carlo simulation engine modeling algorithmic collusion and Bertrand-Nash price competition in differentiated duopoly markets. Powered by WebAssembly (Pyodide) to run Python reinforcement learning algorithms directly in the browser, featuring real-time state synchronization, dynamic action spaces, and closed-form economic benchmarks.
